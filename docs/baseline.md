## 已接入的离线核心

`her_agent/` 保留现有模块名以减少迁移改动，现阶段包含：显式作者包读取与输入编译、SQLite 记忆及来源、上下文与后台维护、轮次生成与交付结算，以及不联网的合成演示。模块名不代表整套原运行环境已迁入。

这批代码使用 Python 3.10+ 标准库；记忆锁使用 `fcntl`，当前适用于 macOS／Linux，不支持原生 Windows Python。人物作者包由调用者显式提供；演示与测试只使用合成角色，在临时目录建立并删除测试数据库。没有载入 Jo 作者稿、已有私聊或真实记忆。

```sh
python3 -S -B -m unittest discover -s tests -v
python3 -S -B -m her_agent.demo
```
