## 本仓实际包含

| 部分 | 入口与边界 |
| --- | --- |
| 人物与会话 | `her_agent/author.py`、`runtime.py`；显式人物包、原话与实际交付分别处理，运行日期默认LA；保留旧模块名不构成外部仓库依赖 |
| 记忆与工具 | SQLite、来源读回、纠正／遗忘、临时交流、后台维护；原记忆工具环与显式地方查询环目前分开，不能同时开启 |
| 地方查询 | PR #14、#16 接入条目、登记来源、结果事件和文字查询／卡片对象；默认通话尚未消费。真实读取候选见下节 |
| 模型与费用 | 本仓DeepSeek流式provider；actor、工具续接、JSON维护共用余额与费用入口，失败／未知usage保留预留，不持久化请求正文 |
| 语音与页面 | LiveKit1.8.4、Paraformer、VoxCPM2 HTTP、能量VAD、独立页面与vendored JS；保留打断、交付不确定、重拨与页面代次隔离 |
| 运行入口 | 文字CLI、默认离线检查的语音启动器、可选GPU服务；不运行git patch、不发现旧工作目录或宿主账户、不自动启用设备 |
| 私有资源 | 操作者明确配置的作者包、密钥、模型、声音和状态；公开仓附合成包，无原始私聊、原声或模型权重 |

`ANGELENO_DATA_DIR` 默认本仓 `private/state`，文字和语音都禁止将记忆／费用账本写出本仓private目录。身份、schema、seed及库占用检查保留，默认不创建缺失身份。公开示例包与完整Jo包分开，界面显示实际配置身份。

## 真实来源读取候选（2026-10-31）

基于 main `53e2598`，关联 Issue #11／#1。新增有界真实 HTTPS 读取器、同组 DNS 地址校验、实际 HTML 时段解析及异步取消；实模文字入口不再读取人工 fixture。来源卡片仍是核心对象，浏览器与语音整合未完成。

实际观察：已登记页面通过普通 HTTP 客户端取得完整 HTML，Fisher 为 437,639 字节，NHM 为 132,852 字节。新生产读取器在当前机器上对二者都返回 `unavailable / dns_non_public`（2026-10-31T04:10:30-07:00）；没有连接拒绝的地址或通过代理绕过。保存的 HTML 仅供本地解析核验：NHM 的 2026-11-03 按首个周二规则为闭馆；Fisher 保留例外但不足以确定。**这不是生产源端到端读取成功**，登记 `last_success` 保持空。

离线回归覆盖混合公网／私网 DNS、地址重用、跳转限额、HTTP／编码／体积失败、整体超时、取消与迟到结果、实际页面形状的日期规则及未知公告。现有文字测试和演示各有一个日历断言，在未改 main 上也会因当前日期／星期失败；本候选检查旧事实与会话／工具内容，保留来源和记忆断言。

本候选 `UV_OFFLINE=1 make verify` 通过：223 项 Python、2 项假 GPU、6 项页面回归，以及门禁负向自检、示例预览、连续性演示与 diff 检查。新增 15 项读取／解析与共享循环回归使用合成传输，没有付费模型或真实音频。原始命令输出保留执行 checkout 的 ignored `tmp/verify.log`；主线反例保留 `tmp/baseline-lookup.log` 与 `tmp/baseline-demo.log`。

后续仍需：在真实公网 DNS 的获准环境取得产品读取证据；处理 Fisher 校历依赖；合并地方／记忆工具环、接通语音与页面事件，再取得获准实模和声音证据。本候选没有付费模型／ASR／TTS、暂停设备、部署或私有资源迁移。
