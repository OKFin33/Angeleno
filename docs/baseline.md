| 部分 | 入口与边界 |
| --- | --- |

## 真实来源读取候选（2026-10-31）

PR #17 基于 main `53e2598`，关联 Issue #11／#1。新增有界真实 HTTPS 读取器、同组 DNS 地址校验、实际 HTML 时段解析及异步取消；实模文字入口不再读取人工 fixture。该阶段卡片仍是核心对象，后续接线见下一节。

实际观察：已登记页面通过普通 HTTP 客户端取得完整 HTML，Fisher 为 437,639 字节，NHM 为 132,852 字节。新生产读取器在当前机器上对二者都返回 `unavailable / dns_non_public`（2026-10-31T04:10:30-07:00）；没有连接拒绝的地址或通过代理绕过。保存的 HTML 仅供本地解析核验：审阅修复后 NHM 因仍有未解释公告返回信息不足，Fisher 因校历例外未解决返回信息不足。**这不是生产源端到端读取成功**，登记 `last_success` 保持空。

离线回归覆盖混合公网／私网 DNS、地址重用、跳转限额、HTTP／编码／体积失败、整体超时、取消与迟到结果、实际页面形状的日期规则及未知公告。现有文字测试和演示各有一个日历断言，在未改 main 上也会因当前日期／星期失败；本候选检查旧事实与会话／工具内容，保留来源和记忆断言。

本候选 `UV_OFFLINE=1 make verify` 通过：224 项 Python、2 项假 GPU、6 项页面回归，以及门禁负向自检、示例预览、连续性演示与 diff 检查。新增 16 项读取／解析与共享循环回归使用合成传输，没有付费模型或真实音频。原始命令输出保留执行 checkout 的 ignored `tmp/verify.log`；主线反例保留 `tmp/baseline-lookup.log` 与 `tmp/baseline-demo.log`。

独立审阅初候选 `29f1528` 发现两项阻断：公告关键词过滤遗漏 “We will not open tomorrow.”，以及畸形跳转主机／端口抛出未归一化异常。当前候选对任何未解释非空公告均保留不足，并在跳转解析边界转换为 `unavailable`；补反例、单次请求、响应关闭与无结论回归，取消继续向上传递。新候选复核由原审阅流程继续。

后续仍需：在真实公网 DNS 的获准环境取得产品读取证据；处理 Fisher 校历依赖；取得获准实模和声音证据。本候选没有付费模型／ASR／TTS、暂停设备、部署或私有资源迁移。

## 首音、查证结论期限与媒体恢复候选（2026-10-31）

叠加 PR #18 的 `0dcf3cb`，实现 Spec 原有 15／30 秒保护，没有调整数值或体验接受标准。时钟从匹配的 ASR final 或已确认用户项开始；没有这些信号的程序输入明确记为 generation_start。普通回答以服务端开始播放为观察，查证轮次另等工具返回后的回答音频，等待提示和卡片均不解除或重置 30 秒期限。超时取消该轮模型、查询、TTS 与排队音频，并定向显示可继续说话的状态；清理失败才停止整通电话。

TTS 保留共享核心文本的轮次／阶段标记，按句合成；等待和回答在音频叶节点分段排空，上层字幕同步器仍接收整轮的一次完成。过期帧在接收前拒绝，不靠生成文字或字幕判断已出声。按句合成会重新应用现有 VoxCPM 预缓冲，真实韵律和延迟需实测。内存只保留最近 100 轮的标识、确认锚点及事件时间，不保存原话或原始音频，不声称已经具备全段真人计时证据。

作者自检先在 252 项 Python 门禁通过后，补入生产字幕同步器接合，发现直接在其上方分段会丢失字幕；已改为叶节点分段并保留回归。失败原始输出在 ignored `tmp/voice-deadline-sync.log`。最终 `UV_OFFLINE=1 make verify` 通过：254 项 Python、2 项假 GPU、13 组页面及门禁／预览／演示；输出在 `tmp/voice-deadlines-final-verify.log`。新增 17 项 Python 使用实际 LiveKit SDK、合成音频／来源和假 HTTP，覆盖模型／TTS／首帧输出卡住、提示音不抵期限、来源失败可继续、过期音频、ASR锚点、临时不写、定向状态及字幕接合后恢复。页面只增加既有状态栏／toast的超时状态，不决定新视觉。

服务端播放起点不证明人耳听见，也不能判断模型在工具返回后说的首句是否构成有效结论。实际麦克风、来源网络、付费模型／ASR／TTS、完整 Jo 语音、延迟冻结、浏览器视觉检查及 Owner 接受尚未完成。完整产品仍由 Issue #11／#12 验收。
