# 共用核对环

本文描述文字与语音共用的核对环及真实来源读取候选。worker 可显式启用同一核心，并通过独立通道向页面投递卡片；接线已离线验证，真实声音尚未验收。行为依据是 [Spec](spec.md) 第 3、4、6 节，离线来源契约沿 [places](places.md)，当前验证见 [baseline](baseline.md)。

## 闭环

`TextLookup` 接在 `ConversationRuntime` 上，只在显式传入时启用；可同时启用当前身份的 `memory_search`。一个用户轮次最多三次工具调用，每类最多一次（记忆搜索、地方检索、核对、取消），模型请求最多四次。最后一次请求不给工具定义，意外追加工具调用拒绝。每次请求的字符预算包含工具定义、协议与证据，记忆的精确暴露记录及临时不落盘规则沿用原核心。

`place_search` 通常只需地名或别称 `query`。可选 `place_id`／`area` 的有效值由当前目录写入工具定义，不能把城市名当作区域标识。返回的 `scope` 保留查询与实际筛选范围；无效筛选返回 `invalid_arguments`、`coverage_gap: null`，不等同于未收录，也不自动丢掉筛选扩大查询。有效筛选无命中只表示该范围资料不足。参数错误仍消耗本轮唯一搜索机会，不能追加搜索或凭猜测继续来源核对。

离线时间用调用方传入的 `FixedClock`，按 `America/Los_Angeles` 解释。测试夹具不走网络。默认构造仍只读 `data/places/` 冻结页面；真实读取必须显式使用下述适配器，不从 fixture 降级生成现实结论。

一条注册来源上的文字环是：

1. 查询。检索条目，再对登记来源做当下核对。来源卡片跟这一轮回复一起放在 `turn.source_card`，不写进 TTS 文本。
2. 补充。`place_check` 且 `supplement` 为 true：原话不变，旧请求取消，按新的适用日期重查。
3. 取消。当前卡片变为 `cancelled`，结论为空。读已经发生时，结论也不会交给后续模型请求。
4. 换题。不再开新的核对时，不把上一张卡片改写成新题目的结论，也不把上一轮的工具结果放进新轮次。

同一轮的后续请求可以看到刚刚核对到的证据，否则人物无法据实回答。下一轮的演员请求只从已交付对白重新汇编，不携带上一轮的工具协议、请求标识或来源事件。

## 记忆

生成全文不是交付。`delivered(..., complete=True)` 之后，才把仍有效的来源结果写入 `lookup_results`。写入文本必须等于已经落库的完整助手回复。取消、未交付、临时对话和交付中断不写这张表。

这张表是附加结果记录。`meta.schema` 保持 `2`。只打开旧库不会建表，也不会改已有记忆行。`forget` 会清掉对应结果；全清会删光这张表的行。结果记录不进入下一轮的 `context`。

人物种子、已有记忆和来源登记都不因这次核对被改写。`last_success` 仍为空。

## 真实来源读取候选

2026-10-31：`her_agent/live_sources.py` 把实际 HTTPS 页面接到现有结果事件。`places` 包仍是纯离线契约。生产读取仅尝试既定 Fisher／NHM 访问页，现只解释开放时间；其他来源或问题类型返回不可用／范围外。

- 连接使用校验后的同一组 DNS 地址；任一地址不是公网即拒绝。保持 TLS 主机名校验，不使用环境代理、Cookie、凭据或私人会话内容。DNS 返回代理 fake-IP 的机器会被拒绝，不为连通绕过。
- 每跳只到精确登记 URL，最多两次 HTTP 请求；DNS、TLS、跳转和完整读取合用 10 秒期限。页面实测约 438 KB／133 KB，因此生产传输上限为 512 KiB；证据仍受 4,000 字符上限约束。超限、编码压缩、非 HTML、空白、失败和超时明确不可用。没有自动重试或 fixture 回退。
- 解析实际可见的 Hours 区域，不读取脚本或样本专用 `data-claim`。NHM 只接受完整已观察规则：通常时段、每月首个周二的夏季例外、列明节假日。未知句式、任何尚未解释的非空公告、重复或缺失区域保留不确定性；不以关键词判断公告是否影响开放。当前连交通公告也保守返回信息不足，答案表述为页面公布规则。
- Fisher 的校历例外未完整列出，FAQ 时间也不一致，当前保留开放与例外摘录、返回信息不足，不猜年份或修正网页。解析保存的 HTML 成功不更新登记 `last_success`。
- I/O 可取消；取消立即失效当前请求，挂断取消向上传递。读取器即使忽略取消，所在任务仍在发布和后续模型请求前拒绝迟到结果。

不调用模型的显式网络探针：

```sh
.venv/bin/python -m her_agent.live_sources
# 默认 disabled，零网络。以下命令才读取公开页面：
.venv/bin/python -m her_agent.live_sources --fetch --source src.nhm.visit --date 2026-11-03
```

退出码 0 仅表示该次结果 `supported`；1 表示不足、不可用等，JSON 保留状态和原因，不证明人物表现或真实语音通过。

## 有界实模调用

2026-10-31 已按用户许可完成公开合成包与 Jo 包各一个有界文字轮次，分别实际调用两次现有 DeepSeek，usage 完整。Jo 轮次的参数记录发现模型把 `Los Angeles` 作为精确 area 传入，旧工具将它误报为资料覆盖不足，未进入来源核对。当前修正参数契约；完整来源成功路径及真实语音仍未验证。用量、人物输出与原始回执只保存在操作者 private，非本单元导入副作用。

默认命令不调用模型：

```sh
python -m her_agent.lookup
```

它打印 `bounded real-model run: disabled`，并以 0 退出。

同时满足 `--live`、进程环境 `ANGELENO_LOOKUP_LIVE=1` 和一句 `--utterance` 时，命令才会尝试**一次**付费演员轮次（最多四次模型请求）。该路径仍走现有付费开关和余额账本；缺配置时由原有入口拒绝。上述实测用同一 provider／runtime 的有界脚本额外留存必要工具参数与私有用量回执，没有改变默认关闭状态。

该入口只用真实读取器，移除了会把人工样本日期带入实模的 `--instant` 参数；时间在每个用户轮次开始时刷新为当前 LA 日期，`checked_at` 取实际读取时刻。固定时钟与样本只留在离线测试，跨 LA 午夜的刷新已有回归。

## 语音与页面

现有语音启动入口在 `ANGELENO_PLACE_TOOLS=1` 时创建实时读取器；默认 `0`。与 `ANGELENO_MEMORY_TOOLS=1` 同开即使用上述共用循环。所有模型续接仍走原付费入口，设置开关本身不改变运行授权、私有资源或预算。

`ResultChannel` 在核对、结果、取消时发出独立卡片观察事件。`VoiceCards` 通过 LiveKit reliable data 的 `angeleno.source` topic 定向发给本次服务器签发 token 的身份，接收者由 dispatch metadata 绑定；缺失身份拒绝启动，不广播到整个房间。单槽队列合并尚未发送的旧状态，发送前再次检查卡片仍有效；2 秒投递期限、无重试，传输失败停止通话。包上限 14,000 字节，超出时只省略可选摘录，仍过大则拒绝。来源名和 URL 来自登记表。

浏览器只接受本次房间的 agent、当前接收者、同一来源会话和递增序号。卡片原位更新，未知协议丢弃；文本用 `textContent`，链接仅允许 HTTPS。挂断保留最后卡片，重拨清空，旧房间回调不再生效。卡片从不进入字幕、TTS 或交付证明。实际完整播放才结算 `lookup_results`，取消、临时与不确定交付不写入。

15／30 秒保护及恢复已有离线候选，服务端计时和限制见 [baseline](baseline.md)。尚需实测真实数据包／媒体链路、有效结论首音、插话体验和实际延迟。合成 SDK 播放与假 transport 回归不证明上述验收通过。

### 替换页面时的接口与状态

聊天式原型的生产集成沿用现有 token、房间事件和控制入口，不由原型模拟结果替代服务响应。布局可替换，以下含义保持：

| 输入／入口 | 页面含义与必须保留的边界 |
| --- | --- |
| `connect`／`disconnect`／静音按钮 | 开始、挂断、只切换当前麦克风；连接／退出过程保留 call generation 和旧房间回调检查，不能重拨后复活旧音频 |
| agent状态、连接与播放错误 | `ready/connecting/connected/disconnected/error`；服务 health 不证明实际出声，媒体播放失败有明确停止路径 |
| `angeleno.source` | `{type, recipient, sequence, card}`；当前一张卡片原位更新，按本次房间agent、身份、`card.session_id`、递增序号筛选。`checking/supported/insufficient/conflict/unavailable/cancelled`等状态沿核心枚举，不在界面猜结论 |
| `angeleno.turn_status` | `{type, recipient, session_id, sequence, request_id, state}`；`started`恢复通话状态，`response_timeout/lookup_timeout`提示本轮超时但可继续。可靠定向发送、2秒期限、单槽队列、无重试；页面限2,000字节，拒绝旧会话和乱序，不生成字幕或查证卡 |
| 字幕事件 | 只作字幕；不能据此认定出声、完整交付或事实记忆。来源／运行状态不拼入对白 |
| 纠正／取消／重拨 | 真实纠正／取消经用户输入进入共享核心，不能只在页面把演示卡改字就称已取消查询。挂断使正在核对显示取消并保留最后卡；重拨清卡、清事件绑定，新会话不能消费旧包 |

当前这些状态只复用旧页面状态栏／toast，尚未整合新聊天式设计，不构成视觉接受。

## 测试合并／剪枝提案

不删除、不合并、不跳过现有测试。删除测试须 Owner 批准。

- `tests/test_places_events.py` 与 `tests/test_places_check.py` 锁来源契约。文字环依赖它们，不并入 `tests/test_lookup.py`。
- `tests/test_memory_tool.py` 锁记忆工具环。它与地方核对分开，避免一个失败掩盖另一个。
- 新增测试只锁文字环的新保证：卡片与对白分开、记忆只记实际交付、取消或上一轮结果不进入下一轮。
- 以后若要剪，只考虑新增文件里与契约测试重复的断言，而且仍要 Owner 批准。当前没有可以删的重复，所以没有改旧测试。

## 本单元没有决定的事

- `lookup_results` 要不要升成显式 schema 迁移。现在不升 schema，避免打开旧库时静默改写。
- 用户另报时区时的文字工具参数。时钟契约已能澄清，这条文字环没有加新参数。
- 互动文字入口何时展示卡片。`her_agent` 的命令行入口不在本单元范围内。
