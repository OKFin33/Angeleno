# Angeleno 的产品目标

用户通过实时语音，与具有 LA 背景、偏好和熟悉范围的虚构人物 Jo 交流。体验像向一个来自 LA 的朋友问当地的事：她可以有立场、不全面、不熟悉某些地方；涉及现实安排的关键信息则需要可靠依据。

主要情景是了解当地生活，具体出行安排与查证为辅。用户无须身在 LA，也不必每轮得到推荐或行程。首版中文主用，地名保留自然英文表达；资料做深 Jefferson Park 与 USC／Exposition Park 周边，关注街区日常、建筑与艺术文化。

这一版要验证：人物的取舍、一个有限生活圈的具体知识、对已聊内容的承接，以及对现实问题的及时查证，是否共同构成值得专门使用的交流体验。人物由她关注什么、如何判断和怎样回应体现，不要求每轮自报背景或讲故事。

地方资料先用有来源的 Markdown，当前事实通过登记的官方、机构或场所页面核对。普通聊天不因出现地名就联网；查询时简短说明、可随时插话，补充条件、取消或换题后旧结果失效。页面用一张轻量卡片展示结论、时间和可展开的来源。

改进与同模型、同资料、同工具的普通助手比较，以完整交谈情景判断是否更像向 LA 朋友打听当地，同时要求关键事实不差。文字比较隔离识别噪声；实际语音另验证识别、轮次、插话、播放、延迟与整体体验。实现、离线检查、真实运行和体验接受分别记录。

首版不扩展到全 LA 深度覆盖、开放搜索、预订交易、多角色平台或通话外自主活动。人物身份保持虚构与明确，人物经历要与设定和地方现实相容，现实场所与当下事实可核对。技术与交互约定见 [Spec](spec.md)，当前实现见 [baseline](baseline.md)。
